# Local visual assets

- `public/brand/signal-sculpture.png`: newly generated optical sculpture, used as the main hero artwork. Brief: three interlocking concentric toroidal ribbons, frosted optical glass and brushed pale-blue aluminium, intricate grooves, tilted acoustic-lens arrangement, museum-quality product lighting, uniform deep navy background, no lettering. A single physical metaphor for the three independent signals.
- `design/observatory-reference.png`: generated desktop direction reference. Brief: premium navy and porcelain voice-verification observatory, oversized editorial heading, horizontal navigation, optical torus sculpture at right and an ivory audio workspace beneath. Used for direction, not as a screenshot embedded into the UI.
- `public/brand/logo.jpg`: existing project identity, reused locally.
- `public/fonts/Manrope.ttf`: existing locally supplied font; accompanying license is retained.

Artwork was generated with the image generation tool for this implementation. The visual layout, components, interactions and stylesheet were authored independently in `web2`.
