# Visual reference

`clarity-workspace.png` is a generated desktop workspace concept, produced with the built-in image generation tool. It is a design reference, not a runtime asset or evidence of working functionality. The implementation uses real HTML controls and a deterministic SVG acoustic ribbon; it deliberately preserves the supplied SatyaCheck logo and correct product semantics where the concept differs.
