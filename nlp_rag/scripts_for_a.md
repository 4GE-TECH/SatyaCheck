# Ten scam scripts to record — for A

One per scam family, 4 English / 3 Latin-Hinglish / 3 Devanagari. All are held-out
evaluation transcripts: they were never used to author a corpus document, so
retrieval on them is a real measurement rather than a memory test.

**Name each file exactly after its id**, 16 kHz mono WAV — e.g.
`held-digital-arrest-004.wav`. That filename *is* the ground-truth label, so no
separate manifest is needed. A wav I cannot map back to an id cannot be scored.

Different voice per file where you can; accent and gender variety is useful.
Read them as a caller would speak, not as prose.

